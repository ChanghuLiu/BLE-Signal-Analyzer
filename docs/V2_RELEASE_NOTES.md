# BLE Signal Analyzer 2.0

## New

- Compare two BLE devices in real time
- Dual RSSI comparison graph
- Signal difference measurement
- Signal Stability Score
- Stability statistics
- Advertisement Inspector
- Raw advertisement data viewer
- BLE Environment Analyzer
- Signal distribution summary
- BLE Activity summary
- Export current signal-analysis sessions as CSV

Signal Stability Score is an app-defined relative metric based on RSSI variation and signal
continuity. It is not an official Bluetooth standard measurement.

CSV export is user initiated and generated locally. BLE Signal Analyzer does not upload exported
files or maintain export history.
