Bluetooth scan does not start

  • Check that Bluetooth is enabled.
  • Grant the Nearby Devices permission.
  • On Android 11 or older, ensure the required location permission is granted.

No devices found

  • Move closer to the BLE device.
  • Make sure the BLE device is powered on.
  • Try scanning again.

Signal fluctuates

  • RSSI varies naturally between advertisements.
  • Walls, people, device orientation, antenna design, and radio interference can affect signal strength.
  • Move slowly and compare relative changes over time.

BLE Signal Analyzer provides relative Bluetooth signal measurements and does not provide exact physical distance.
